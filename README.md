# Public Operations Observatory

Public Operations Observatory preserves durable, evidence-linked public product signals and turns them into restrained operating briefings.

The Phase 0 program is intentionally GitHub-first. Its first runnable release, v0.1, will provide a PostgreSQL-backed idempotent GitHub collector, explicit checkpoints and provenance, release/documentation/communication annotations, and a weekly Markdown briefing for Hermes-Relay. It will not include a dashboard, website analytics, Google Play, multi-tenancy, a plugin marketplace, or public action execution.

See:

- [Phase 0 contract](docs/phase-0-contract.md)
- [Website analytics decision](docs/analytics-decision.md)

Website analytics is a separate, approval-gated input. It does not block the GitHub collector or weekly briefing.
